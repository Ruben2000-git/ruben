# Facebook Lead Finder (Handyman, Buffalo NY)

Программа находит потенциальных клиентов в группах Facebook
Marketplace / "Buy and Sell" Buffalo NY по ключевым словам (gutter,
fence repair, siding, drywall, handyman, window repair и т.д.),
оценивает каждый пост через Claude и показывает результат на удобной
мобильной веб-странице.

## ⚠️ Важно прочитать перед использованием

У Facebook **нет** публичных RSS-фидов (как у Craigslist) и
**нет** официального API для чтения постов в чужих группах для
сторонних программ - Meta закрыла Groups API для разработчиков ещё в
2018 году. Получить такой доступ легально, не будучи зарегистрированным
бизнес-партнёром Meta с одобренным приложением, невозможно.

Поэтому эта программа использует **Playwright** - автоматизацию
обычного браузера под **вашим личным логином Facebook**. Технически
это означает, что программа заходит в Facebook и читает ленту групп
точно так же, как это делали бы вы сами, листая телефон. Она:

- заходит ТОЛЬКО в группы, в которых вы лично состоите;
- не обходит никакие блокировки приватности;
- не скрапит закрытые/чужие данные, до которых у вас нет доступа.

Тем не менее, это формально нарушает Условия использования Facebook
(автоматизированный доступ к аккаунту запрещён их правилами), и
реальный риск - **временная или постоянная блокировка вашего
аккаунта Facebook**. Используйте на свой страх и риск, по возможности
заведите для этого отдельный аккаунт, не привязанный к вашим личным
фото и переписке, и не запускайте сбор слишком часто и агрессивно
(в config.py интервал по умолчанию - раз в 20 минут, этого достаточно).

## Что нужно установить (для Windows, без опыта программирования)

### 1. Установить Python

1. Зайдите на https://www.python.org/downloads/
2. Скачайте и установите Python 3.11 или новее.
3. На первом экране установщика обязательно поставьте галочку
   **"Add python.exe to PATH"**.

### 2. Скачать программу

Скопируйте папку `facebook_lead_finder` на свой компьютер, например в
`C:\FacebookLeads`.

### 3. Открыть командную строку в папке программы

1. Откройте папку `C:\FacebookLeads\facebook_lead_finder` в проводнике.
2. В адресной строке проводника введите `cmd` и нажмите Enter -
   откроется командная строка прямо в этой папке.

### 4. Установить зависимости

В открывшейся командной строке по очереди выполните:

```
pip install -r requirements.txt
playwright install chromium
```

Это установит Python-библиотеки и скачает встроенный браузер Chromium,
которым будет управлять программа.

### 5. Настроить ключ Claude API

1. Зайдите на https://console.anthropic.com/ и создайте API-ключ.
2. В командной строке выполните (замените на свой ключ):

```
setx ANTHROPIC_API_KEY "ваш-ключ-сюда"
```

3. Закройте и снова откройте командную строку, чтобы переменная
   применилась.

### 6. Указать ваши группы Facebook

1. Откройте файл `config.py` в Блокноте.
2. В списке `FACEBOOK_GROUPS` впишите ссылки на группы, в которых вы
   состоите, например:

```python
FACEBOOK_GROUPS = [
    "https://www.facebook.com/groups/123456789012345/",
    "https://www.facebook.com/groups/987654321098765/",
]
```

Ссылку на группу можно скопировать прямо из адресной строки браузера,
когда вы открыли эту группу в Facebook.

### 7. Первый запуск и вход в Facebook

Выполните в командной строке:

```
python run.py
```

При первом запуске откроется окно браузера с формой входа Facebook.
Введите ваш логин и пароль (или впишите их заранее в config.py /
переменные окружения `FB_EMAIL` и `FB_PASSWORD`), пройдите проверку
безопасности (2FA, капчу), если она появится - на это даётся 90 секунд.
После этого сессия сохранится в файл `fb_session.json`, и в следующий
раз вводить пароль заново не понадобится.

### 8. Открыть дашборд

После запуска в командной строке появится строка вроде:

```
Запуск Facebook Lead Finder. Дашборд: http://127.0.0.1:5000
```

Откройте этот адрес в браузере на компьютере или телефоне (если телефон
в той же Wi-Fi сети, замените `127.0.0.1` на IP-адрес компьютера).

Программа будет сама проверять группы каждые 20 минут (можно изменить
`SCAN_INTERVAL_MINUTES` в `config.py`). Кнопка **Refresh Now** на
странице запускает проверку немедленно.

## Структура файлов

| Файл | Назначение |
|---|---|
| `config.py` | Все настройки (группы, ключевые слова, API-ключи, интервалы) |
| `db.py` | Общие функции работы с базой данных SQLite |
| `collector.py` | Заходит в Facebook через Playwright и собирает новые посты |
| `filter.py` | Отправляет новые посты в Claude и сохраняет оценку/черновик ответа |
| `app.py` | Flask-дашборд с карточками лидов |
| `run.py` | Запускает дашборд + фоновый планировщик одновременно |
| `facebookleads.log` | Лог-файл со всеми событиями программы |
| `facebookleads.db` | База данных SQLite со всеми найденными постами |

## Частые проблемы

- **Окно браузера не открывается** - убедитесь, что выполнили
  `playwright install chromium`.
- **Аккаунт Facebook требует постоянных проверок безопасности** -
  Facebook заметил автоматизацию. Попробуйте увеличить
  `SCAN_INTERVAL_MINUTES`, использовать `HEADLESS = False` всегда (чтобы
  видеть, что происходит) и не запускать сбор слишком часто.
- **Claude возвращает ошибку** - проверьте, что переменная окружения
  `ANTHROPIC_API_KEY` задана правильно (`echo %ANTHROPIC_API_KEY%` в
  командной строке должен показать ваш ключ).
